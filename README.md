# Welcome to Query4J

## Goals
- Jakarta integration
- SQL-first
- CDI integration
- Entities as records (Java 16+ is required)

## Explicit non-goals
- ORM
- entity state tracking
- lazy loading
- query DSL
- automatic schema generation
- relationship management
- criteria builders
- JPQL equivalent
